# hike-trail-analyzer
通用专业徒步轨迹分析Skill

**Author: Vijay** · 由 Vijay 设计开发并维护
功能说明：
导入一份轨迹文件（支持GPX/KML/KMZ三种格式），自动生成一份专业徒步路书。
输出内容包含：路线总览（里程/爬升/海拔/集合点/预估用时/难度评分）、沿途气象预估、分段坡度路况、卫生间与补给点、风险提示与装备建议（含按当日气温测算的饮水升数与夏季可选装备）。
天气预报使用 wttr.in 公开接口，无需 API Key；按轨迹关键点位和预估到达时刻查询目标日期的 3 小时粒度预报。

难度评分由三项独立归一化指标加权：全程里程 35%、累计爬升 35%、持续上坡 P95 30%。持续坡度使用平滑海拔、30 米重采样和约 200 米窗口计算；分段最陡坡度只作为局部风险提示，不直接把综合难度推到满分。

面向小红书发布时，路书正文固定为 1000 字符（含标点和换行），以完整路书为基础保留关键模块；超限按整行压缩，不足补充有用的行进和安全建议，不靠无意义重复凑字数。

## 使用方式
1. 安装依赖
pip install -r requirements.txt
2. 运行（轨迹文件支持 .gpx / .kml / .kmz）
python main.py <轨迹文件路径> "<路线名称>" [出发日期YYYY-MM-DD] [出发时刻HH:MM]
未指定出发时间时默认明天 09:00 出发（出行日期=运行当天+1天，绝不取轨迹文件内的历史时间戳），路书直接在终端完整输出，可直接复制使用

## 调用方式
外部可调用 run_hike_analysis(轨迹路径,路线名称,可选自定义出发时间)
